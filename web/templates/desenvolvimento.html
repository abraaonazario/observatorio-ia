Desenvolvimento Tecnológico

A arquitetura do DataLuta foi desenvolvida utilizando um conjunto de tecnologias de ponta em Inteligência Artificial, Ciência de Dados e Engenharia de Software. Abaixo, detalhamos o stack tecnológico que sustenta nosso pipeline analítico.

Nível de Maturidade da IA (0 a 5)

O Observatório IA evolui continuamente. Acompanhe a nossa esteira de evolução e o estágio atual do projeto em termos de maturidade de dados e inteligência artificial:

Nível 0: Ad Hoc / Inexistente

Sem processamento estruturado. Dados soltos e sem padronização.

Nível 1: Inicial

Ingestão de dados brutos (PDFs/Planilhas) e extração de texto básica automatizada.

Nível 2: Gerenciado

Dados limpos, estruturados e aplicação de pipeline de NLP com Semantic Chunking.

Nível 3: Definido

Modelos base (HistGradientBoosting/RF) treinados, validados e com métricas de classificação estabelecidas.

Nível 4: Quantitativamente Gerenciado

Modelos de Deep Learning (MT-DNN Multi-Task) implementados, otimizados e embeddings gerados.

Nível 5: Otimizado (Status Atual)

Observabilidade total, RAG semântico extrativo em tempo real, Grafo de Conhecimento interativo e georreferenciamento.

Redes Neurais PyTorch (MT-DNN)

O núcleo de classificação preditiva utiliza uma arquitetura profunda de Redes Neurais baseada em Multi-Task Deep Neural Networks construída em PyTorch, capaz de aprender múltiplas dimensões do conflito simultaneamente.

Processamento de Linguagem (spaCy)

A segmentação de textos complexos (chunking), identificação de classes gramaticais e pré-processamento estrutural (NLP) são garantidos pelos modelos robustos pré-treinados do spaCy para a língua portuguesa.

Busca Semântica (Sentence-Transformers)

Para extração de embeddings e vetorização de sentenças, implementamos a biblioteca Transformers (Hugging Face), permitindo buscas contextuais avançadas independentes de palavras-chave exatas.

Extração de Dados (PDFPlumber)

A leitura e extração programática de textos brutos a partir de dossiês documentais e laudos periciais digitalizados (arquivos PDF) são feitas via PDFPlumber.

Interface Web (Flask/Python)

A camada de visualização, roteamento de APIs e interface com o usuário final é sustentada por um servidor em Flask, integrado com Jinja2 para renderização dinâmica.

Arquitetura de Pastas (Pipeline de Código)

O Observatório foi construído de forma modular. Cada pasta do código-fonte tem uma responsabilidade estrita no ciclo de vida do dado, funcionando como uma linha de montagem industrial. Abaixo está o fluxo de execução de cada módulo:

1

/ingestion

O que faz: É a "boca" do sistema. Este módulo entra nos arquivos ZIP, lê a planilha Excel principal e usa o PDFPlumber para extrair a matéria bruta dos PDFs sem que o usuário precise descompactar nada manualmente.

2

/preprocessing

O que faz: É o "lavador". Recebe o texto sujo da ingestão, aplica as baterias de limpeza com Expressões Regulares (eliminando links, hifens e menus) e usa o spaCy para fatiar o texto em "Chunks" lógicos.

3

/embeddings

O que faz: É o "tradutor matemático". Contém o Dicionário de Enriquecimento Semântico. Ele transforma os textos em números (vetores), criando a base de conhecimento (RAG) que a IA usará para buscar similaridades.

4

/training

O que faz: É a "escola". Contém os scripts que ensinam a IA. Pega os dados estruturados e roda os algoritmos de Machine Learning (HistGradientBoosting/MT-DNN) para treinar as predições de classificação sociológica.

5

/models

O que faz: É a "memória" física. Guarda os arquivos binários (.pkl, .bin) gerados na etapa de treinamento, preservando o "cérebro" da IA pronto para o uso na Web.

Fluxo Algorítmico da Inteligência Artificial

O coração analítico do Observatório não é uma única IA genérica (como o ChatGPT), mas sim um ecossistema de algoritmos hiper-especializados ("Ensemble Learning"). Abaixo está o fluxo exato de como cada algoritmo processa os dados:

1. Extração

PDFPlumber

Visão Computacional. Enxerga a geometria da página e extrai apenas caracteres puros.

2. Higienização

Filtros RegEx

Processamento de Texto. Elimina links, hifens, NUL bytes e formatações indesejadas (ruídos).

3. Estruturação

spaCy (NLP)

Linguística. Analisa a gramática e corta o texto gigante em "Chunks" lógicos.

4. Vetorização

DistilUSE

Matemática Semântica. Converte palavras limpas em coordenadas vetoriais matemáticas.

5. Predição

Machine Learning

Árvores de Decisão. Lê os vetores e prediz se é Ação Matriz ou Derivada.
